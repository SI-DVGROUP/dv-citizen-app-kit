# Spécifications

Chaque changement significatif est relié à une spécification. Conserver la demande originale, les règles métier confirmées, les données, les intégrations, les décisions, les tests et la validation fonctionnelle. Utiliser `.agent/templates/specification.md`.

- `active/` : demandes en cours ou en attente de clarification.
- `blocked/` : demandes interrompues dans l'attente d'une décision ou d'une autorisation.
- `completed/` : demandes validées fonctionnellement par le Citizen.

Ne déplacer une spec vers `completed/` qu'après validation explicite. Une demande bloquée ne justifie jamais un contournement.
