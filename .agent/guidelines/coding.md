# Recommandations de code

- [MUST] Suivre les conventions, frontières de responsabilité et styles déjà présents dans le projet.
- [MUST] Limiter le changement au besoin spécifié et préserver les comportements existants hors périmètre.
- [MUST] Réutiliser les composants et utilitaires existants avant d'en créer de nouveaux.
- [SHOULD] Préférer la solution la plus simple qui satisfait les règles métier et les exigences de sécurité ; documenter les écarts.
- [MUST] Traiter les erreurs de manière explicite et compréhensible pour l'utilisateur, sans exposer de détails sensibles.
- [MAY] Ajouter des commentaires uniquement lorsqu'ils clarifient une décision ou une logique difficile à déduire du code.

Ces recommandations ne définissent pas de langage ni de framework ; se référer à `.agent/charter/stack.md`.
