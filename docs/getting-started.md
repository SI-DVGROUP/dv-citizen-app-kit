1. Créez le dépôt applicatif du projet dans l'organisation approuvée par DV Group et conservez les règles de ce kit.
2. Décrivez le besoin métier en langage naturel. Pour une feature conforme à la stack et aux capacités préapprouvées, l'agent réalise le code applicatif, les tests et les fixtures sans attendre une validation manuelle de l'équipe plateforme.
3. Répondez uniquement aux questions métier réellement bloquantes. Les choix techniques restent déterminés par `.agent/charter/`.
4. Utilisez les commandes de démarrage et de vérification présentes dans les manifests du dépôt applicatif ; ce kit documentaire ne fournit pas de commande exécutable.
5. Testez le parcours et consignez votre validation fonctionnelle dans la spécification.

Une feature standard et ses fixtures peuvent être développées et testées localement sans attendre la livraison. Seule une capacité hors cadre préapprouvé ou un accès à un environnement partagé/production suit le workflow d'escalade. Les changements indépendants continuent dans le dépôt applicatif.
